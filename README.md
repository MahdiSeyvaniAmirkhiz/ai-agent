# ai-agent

This repo contains a simple HTML page for sending article information to an n8n webhook.

## Usage
1. Open `index.html` in your browser.
2. Change the `webhookUrl` variable at the bottom of the file to your n8n webhook address.
3. Fill the form and submit to send the data.

Only the beginning of the form is implemented. You can extend the rest of the fields where the comment `<!-- more fields here -->` is located.
