# Music Visualizer Desktop App

This project is a desktop music player that applies real-time visual effects to a webcam feed or video source. The intensity of effects reacts to the currently playing music.

## Dependencies

- Python 3.8+
- PyQt5
- OpenCV
- numpy
- pydub

Install dependencies with:

```bash
pip install PyQt5 opencv-python numpy pydub
```

## Run

```bash
python -m music_visualizer.main
```

Inside the application you can choose audio and video files or use your webcam. Sliders allow you to control effect parameters and change the video source.
